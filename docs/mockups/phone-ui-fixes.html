Fix 1 · high

No more room code

The TV stopped showing the room code in #28, but the join page still asks for one. You picked option (b): when the page has no code, the relay hands over the one room it runs.

  • The room code box goes away.
  • The hint now tells you you're joining the game on the TV.
  • A QR scan still works the same way as before.

Fixes 3 + 4 · medium

A ranked scoreboard that matches the TV

The phone lists players in the order they joined, so on the results screen the winner can be third in the list. After the fix the list is sorted and numbered, and your own row stands out.

Your last throw uses the TV's wording, so a throw reads the same on the phone and on the TV.
