# AJ's Motion Controls — docs

AJ's Motion Controls turns a phone into a game controller for a Windows PC: on-screen buttons and
sticks, plus the phone's motion sensors, with no app to install. The phone opens a web page; the
PC passes what it receives to emulators (Dolphin, Cemu, Ryujinx, the Citra forks) and, later, to
any game as a virtual Xbox controller. It works offline, over a hotspot the PC runs itself.

This repo was forked from the Rock Skipping game, whose phone-controller code it reuses. The game's
own code and some of its documents are still here; the landing page says which is which.
