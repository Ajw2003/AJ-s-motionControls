When it doesn't go to plan

Known failure points

PC offline too long

Certificate expired

The launcher says so before starting the hotspot: "Connect to the internet for a minute to renew." Phones would otherwise get a certificate warning.

Untested

Phone keeps using mobile data

If the internet-check answers aren't enough on a phone model, it won't reach the PC. Fallback: turn mobile data off. Your Android phone is the first test.

Untested

Android Private DNS set to a fixed provider

The phone may skip the hotspot's DNS, so the name doesn't point at the PC. The pre-flight check (#15) should spot it and say which setting to change.

Outside our control

DuckDNS down at renewal

Renewal waits and retries. The current certificate keeps working until it expires, and play never needs DuckDNS.
