# RockSkipping — docs

RockSkipping is a couch party game. A PC runs Unity and drives the TV; players use their phones as
motion controllers through a web page, so nobody installs anything. Up to eight players take turns
throwing a stone across water, and the phone's real swing decides how the stone skips.
The PC decides everything; the phones only send sensor data.
